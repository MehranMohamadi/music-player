Noor 1.0.0 — native offline Android music player.

برای نصب، فایل **Noor.apk** را از بخش Assets دانلود کنید. اندروید ۱۱ یا بالاتر لازم است.

- Local music library, background playback, playlists, favorites, queue, search, and Persian/RTL UI.
- Bulk collection management and Android-approved physical file deletion.
- Physical tag/artwork editing for MP3, FLAC, and Vorbis OGG.

**Download:** `Noor.apk` is the optimized, installable APK (~6 MiB), signed with the development/test key. This is an evaluation build, not a production-signed store release. The signing key is not included in this repository.

**Validation:** debug and optimized release builds succeeded; 21 unit tests passed; lint reported zero errors. Eight instrumented device tests compiled but could not run because the cloud emulator failed before app execution. Physical-device behavior remains unverified.

`SHA256SUMS` records the exact APK attached here (its repository path is `distribution/Noor.apk`; after downloading both assets, use `sha256sum Noor.apk` to compare).
